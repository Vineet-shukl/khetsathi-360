1. DAP (18-46-0) kg = Target P₂O₅ (kg) ÷ 0.46

3. Remaining N (kg) = Target N (kg) - N-Credit from DAP
4. Urea (46% N) kg = Remaining N (kg) ÷ 0.46
5. MOP (60% K₂O) kg = Target K₂O (kg) ÷ 0.60
